# Industrial Vision

Учебный проект по разработке программного модуля технического зрения
для промышленного мобильного роботизированного комплекса.

## Назначение

Модуль предназначен для анализа видеопотока, обнаружения людей
и транспорта, проверки контролируемых зон, контроля средств
индивидуальной защиты и выявления визуальных признаков дыма,
огня и разлива.

Результаты анализа будут преобразовываться в события с сохранением
JSON и подтверждающего кадра. Доступ к состоянию системы и событиям
будет предоставляться через REST API.

## Запуск

Команды выполняются из корня проекта:

```bash
source .venv/bin/activate
python -m src.main
```

Программа загружает конфигурацию и модель, открывает источник
видео и отображает результаты детекции.

На изображении выводятся:

- рамки объектов, названия классов и confidence;
- FPS общего цикла обработки;
- время вызова детектора в миллисекундах;
- количество детекций текущего кадра.

Выход: q или Esc при активном окне, Ctrl+C в терминале.
После завершения видеофайла программа останавливается.

Журнал сохраняется в logs/application.log.

## Конфигурация

Основные настройки находятся в configs/configuration.yaml:

- camera — источник видео и параметры подключения;
- models — пути к моделям и пороги confidence;
- zones — полигоны контролируемых областей;
- events — временное подтверждение и cooldown событий;
- storage — расположение и срок хранения событий.

Пути data/test.mp4 и models/detector.pt являются начальными
настройками. Соответствующие файлы будут добавлены на следующих этапах.

## Baseline-детектор

Используется предобученная на COCO модель YOLO26n
из библиотеки Ultralytics.

Веса: models/yolo26n.pt.

Документация модели:
https://docs.ultralytics.com/models/yolo26/

Модель выполняется на CPU.
Параметры задаются в блоке models файла
configs/configuration.yaml.

При конфигурации classes: [0, 1, 2, 3, 5, 7]
обрабатываются классы person, bicycle, car,
motorcycle, bus и truck.

Детектор возвращает список Detection:
class_id, class_name, confidence, x1, y1, x2, y2.
Координаты рамок выражены в пикселях исходного кадра.

Для получения весов из корня проекта:

    mkdir -p models
    python -c "from ultralytics import YOLO; YOLO('models/yolo26n.pt')"

Веса и видеоданные не включены в Git.

## Предварительные результаты и ограничения

В представленном тестовом запуске значения FPS в журнале
после начального запуска составляли примерно 17–23.
Время отдельных вызовов детектора составляло примерно 26–37 мс.
Это наблюдения одного запуска, а не итоговый benchmark.

На тестовых видео обнаруживаются люди и транспорт.
Наблюдаются пропуски объектов и исчезновение рамок
на отдельных кадрах.
