# Датасеты проекта

## Каски и жилеты (PPE v2)

Датасет подготовлен для дообучения детектора защитных касок
и сигнальных жилетов в проекте Industrial Vision.

Модель определяет видимые предметы СИЗ.
Сопоставление экипировки конкретному человеку и формирование
событий нарушения выполняются отдельной логикой.

### Источники

Использованы два открытых набора.

- [Construction-PPE](https://docs.ultralytics.com/datasets/detect/construction-ppe/).
- [Color Helmet and Vest (CHV)](https://github.com/ZijianWang-ZW/PPE_detection).

Construction-PPE используется для обучения.
CHV используется для validation и test.

Использована готовая разметка, адаптированная под два класса.
Собственная ручная разметка в этом эксперименте не добавлялась.

### Подготовка классов

| Источник | Исходный ID | Исходный класс | Итоговый ID |
|---|---:|---|---:|
| Construction-PPE | 0 | helmet | 0 |
| Construction-PPE | 2 | vest | 1 |
| CHV | 1 | vest | 1 |
| CHV | 2 | blue helmet | 0 |
| CHV | 3 | red helmet | 0 |
| CHV | 4 | white helmet | 0 |
| CHV | 5 | yellow helmet | 0 |

Аннотации остальных классов исключены.
Все цвета касок объединены в helmet.
Координаты выбранных рамок сохранены.

### Формат разметки

Итоговые классы перечислены ниже.

- 0 — helmet;
- 1 — vest.

Используется формат Ultralytics YOLO Detection.
Изображению соответствует TXT с таким же именем.
В каждой строке есть номер класса и четыре значения для рамки.

```text
class_id x_center y_center width height
```

Координаты центра, ширина и высота нормированы
относительно размеров изображения.

Используются исходные рамки предметов СИЗ.
При дальнейшем расширении набора необходимо последовательно
применять правила границ объектов и частичных перекрытий.

### Размер и разделение

| Часть | Источник | Изображения |
|---|---|---:|
| train | Construction-PPE | 1132 |
| val | CHV | 243 |
| test | CHV | 243 |
| Всего | | 1618 |

Соотношение составляет примерно 70/15/15.
Количество изображений и файлов разметки подтверждено
подсчётом в блокноте второго эксперимента.

Из Construction-PPE взята только подготовленная train-часть.
Изображения CHV отсортированы и перемешаны с seed=42.
Для val и test выбраны два непересекающихся по файлам отрезка.

Неиспользованные изображения остаются в исходных каталогах.
Старые val и test Construction-PPE в эксперименте ppe_exp02
не используются.

В папке `datasets/ppe_v2_simple` при повторной проверке найдена общая сцена.
`images/train/image812.jpg` и `images/test/ppe_0974.jpg` показывают одних и тех же людей в одном месте.
Разбиение делалось по файлам. Полный поиск похожих кадров и разбиение по исходным съёмкам ещё предстоят.
Из-за этого тестовые метрики нужно трактовать как результат этого эксперимента с пересечением сцен.

Датасет готовится скриптами [prepare_ppe.py](../scripts/prepare_ppe.py)
и [prepare_ppe_v2.py](../scripts/prepare_ppe_v2.py). Локальная конфигурация — [dataset.yaml](../configs/dataset.yaml).

Одно изображение может содержать несколько объектов. Пустая разметка означает, что на кадре нет аннотаций касок и жилетов.

### Проверка данных и отрицательные примеры

Выполнено сравнение валидационной разметки
и предсказаний модели на сохранённых примерах.

На крупных и средних объектах модель успешно обнаруживает
каски и жилеты при разных ракурсах.

В наборе присутствуют люди в обычной одежде и сцены
без целевых аннотаций.

Выделены примеры для дальнейшего анализа hard negatives:
дорожные конусы, яркие элементы ограждений и обычная одежда,
которые могут быть похожи на СИЗ.

### Ограничения

- Train и val/test получены из разных источников,
  поэтому различаются условия съёмки и особенности разметки.
- Мелкие, дальние и перекрытые объекты обнаруживаются
  менее стабильно.
- Возможны неточности исходных аннотаций.
- Пересечение сцен ограничивает независимость оценки.
- Качество на камере движущегося робота пока не измерено.

### Результат обучения

Датасет успешно использован в эксперименте ppe_exp02.

При максимуме 30 эпох ранняя остановка завершила обучение
после 18 эпох. Лучшие веса относятся к эпохе 8.

Финальная проверка best.pt на validation:

| Метрика | Значение |
|---|---:|
| Precision | 0.7932 |
| Recall | 0.6567 |
| mAP50 | 0.7078 |
| mAP50–95 | 0.3401 |

В проекте используется `models/best.pt` из этого эксперимента.
Подбор порога на validation и оценка касок на test приведены в [отдельном документе](helmet_thresholds.md).

## Разливы

Для модели `spill_yolo26n-seg_new.pt` использован набор `datasets/spill_mixed_yolo`.
В нём один класс `0 — spill`. Разметка хранится в формате YOLO Segmentation.
Строка в TXT содержит номер класса и координаты вершин контура. На кадрах без разлива TXT пустой.

| Источник | Train | Val |
|---|---:|---:|
| Набор `spill_yolo_seg`, включая добавленные фото пола без разлива | 597 | 34 |
| Отобранные кадры из Roboflow `oil_spill` v1 | 156 | 0 |
| PIAP Liquid Dataset | 86 | 22 |
| Всего | 839 | 56 |
| Из них без разлива | 33 | 7 |

Для validation отложены целые серии PIAP на терракотовой плитке.
В текущем наборе есть train и val. Проверка на других видео проводится отдельно.

[Скрипт сборки](../scripts/prepare_spill_mixed.py) создаёт папку и архив `datasets/spill_mixed_yolo.zip`.
В [блокноте Colab](../scripts/train_spill_mixed_colab.ipynb) YOLO26n-seg дообучалась 60 эпох при размере входа 640.
Для масок на val получены mAP50 **0,478** и mAP50–95 **0,350**. Это результат на 56 изображениях из этого набора.
На новых видео возможны пропуски и ложные маски.
