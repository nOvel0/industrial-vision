# Dataset Card: PPE v2 — каски и жилеты

## Назначение

Датасет подготовлен для дообучения детектора защитных касок
и сигнальных жилетов в проекте Industrial Vision.

Модель определяет видимые предметы СИЗ.
Сопоставление экипировки конкретному человеку и формирование
событий нарушения выполняются отдельной логикой.

## Источники

Использованы два открытых набора:

- Construction-PPE:
  https://docs.ultralytics.com/datasets/detect/construction-ppe/
- Color Helmet and Vest — CHV:
  https://github.com/ZijianWang-ZW/PPE_detection

Construction-PPE используется для обучения.
CHV используется для validation и test.

Использована готовая разметка, адаптированная под два класса.
Собственная ручная разметка в этом эксперименте не добавлялась.

## Подготовка классов

| Источник | Исходный ID | Исходный класс | Итоговый ID |
|---|---:|---|---:|
| Construction-PPE | 0 | helmet | 0 |
| Construction-PPE | 2 | vest | 1 |
| CHV | 1 | vest | 1 |
| CHV | 2 | blue helmet | 0 |
| CHV | 3 | red helmet | 0 |
| CHV | 4 | white helmet | 0 |
| CHV | 5 | yellow helmet | 0 |

Аннотации остальных классов исключены.
Все цвета касок объединены в helmet.
Координаты выбранных рамок сохранены.

## Формат разметки

Итоговые классы:

- 0 — helmet;
- 1 — vest.

Используется формат Ultralytics YOLO Detection.
Изображению соответствует TXT с таким же именем.
Каждая строка содержит:

class_id x_center y_center width height

Координаты центра, ширина и высота нормированы
относительно размеров изображения.

Используются исходные рамки предметов СИЗ.
При дальнейшем расширении набора необходимо последовательно
применять правила границ объектов и частичных перекрытий.

Соотношение составляет примерно 70/15/15.
Количество изображений и файлов разметки подтверждено
подсчётом в блокноте второго эксперимента.

Из Construction-PPE взята только подготовленная train-часть.
Изображения CHV отсортированы и перемешаны с seed=42.
Для val и test выбраны два непересекающихся по файлам отрезка.

Неиспользованные изображения остаются в исходных каталогах.
Старые val и test Construction-PPE в эксперименте ppe_exp02
не используются.

Выполнена визуальная проверка подготовленных выборок:
похожих изображений между частями не обнаружено.
Автоматическая проверка дубликатов и разделение
по идентификаторам исходных видеороликов не выполнялись.

|---|---:|---:|
| helmet | 688 | 241 |

Одно изображение может содержать оба класса.
Количество объектов train и test отдельно ещё не подсчитано.

Сканер Ultralytics отметил 246 фоновых изображений train
и 2 фоновых изображения val.
Повреждённых записей при сканировании train и val не обнаружено.

Фоновый статус означает отсутствие целевых аннотаций.

## Проверка данных и hard negatives

Выполнено сравнение валидационной разметки
и предсказаний модели на сохранённых примерах.

На крупных и средних объектах модель успешно обнаруживает
каски и жилеты при разных ракурсах.

В наборе присутствуют люди в обычной одежде и сцены
без целевых аннотаций.

Выделены примеры для дальнейшего анализа hard negatives:
дорожные конусы, яркие элементы ограждений и обычная одежда,
которые могут быть похожи на СИЗ.

## Ограничения и особенности

- Train и val/test получены из разных источников,
  поэтому различаются условия съёмки и особенности разметки.
- Мелкие, дальние и перекрытые объекты обнаруживаются
  менее стабильно.
- Возможны неточности исходных аннотаций.
- Визуальная проверка не заменяет полный аудит сцен.
- Качество на камере движущегося робота пока не измерено.

## Результат использования

Датасет успешно использован в эксперименте ppe_exp02.

При максимуме 30 эпох ранняя остановка завершила обучение
после 18 эпох. Лучшие веса относятся к эпохе 8.

Финальная проверка best.pt на validation:

| Метрика | Значение |
|---|---:|
| Precision | 0.7932 |
| Recall | 0.6567 |
| mAP50 | 0.7078 |
| mAP50–95 | 0.3401 |

Получена специализированная модель для дальнейшей интеграции.
Тестовая выборка сохранена для итоговой оценки.
