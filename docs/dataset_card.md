# Dataset Card: PPE — каски и жилеты

## Назначение

Датасет подготовлен для дообучения модели обнаружения защитных касок и сигнальных жилетов. Он используется в учебном проекте технического зрения для промышленного мобильного роботизированного комплекса.

Обученная модель определяет видимые предметы СИЗ. На последующих этапах результаты будут сопоставляться с обнаруженными людьми для проверки наличия каски и жилета. Обнаружение людей и транспорта выполняется отдельным baseline-детектором.

## Источник и подготовка

Основой послужил открытый датасет [Construction-PPE](https://docs.ultralytics.com/datasets/detect/construction-ppe/).

[Архив исходного датасета](https://github.com/ultralytics/assets/releases/download/v0.0.0/construction-ppe.zip).

Использована готовая разметка, адаптированная под два целевых класса:

| Исходный ID | Новый ID | Класс |
|---|---|---|
| 0 | 0 | `helmet` |
| 2 | 1 | `vest` |

Аннотации остальных классов исключены. Координаты выбранных рамок сохранены. Изображения без целевых аннотаций оставлены в составе набора как фоновые примеры.

Подготовленный датасет упакован в `ppe.zip` и загружен в Google Colab для обучения. В данном эксперименте использована адаптация существующей разметки без добавления собственной ручной разметки.

## Классы и формат разметки

| ID | Класс | Объект |
|---|---|---|
| 0 | `helmet` | Защитная каска |
| 1 | `vest` | Сигнальный или защитный жилет |

Разметка хранится в формате **Ultralytics YOLO Detection**. Изображению соответствует текстовый файл с таким же именем. Каждая строка описывает один объект:

`class_id x_center y_center width height`

Координаты центра, ширина и высота рамки нормированы относительно размеров изображения.

При адаптации сохранены исходные границы объектов. Для дальнейшего расширения набора приняты следующие правила: размечать сам предмет СИЗ, использовать отдельную рамку для каждого объекта и последовательно учитывать частичные перекрытия.

## Размер и разделение выборки

Сохранено исходное разделение Construction-PPE:

| Часть | Количество изображений | Назначение |
|---|---:|---|
| `train` | 1132 | Обучение модели |
| `val` | 143 | Контроль обучения и выбор лучших весов |
| `test` | 141* | Последующая итоговая проверка |

Пропорция составляет примерно **80/10/10**. Методичка допускает отличие от рекомендуемых 70/15/15; основное внимание должно уделяться отсутствию пересечения сцен.

Сканирование train и val при запуске обучения не выявило повреждённых записей. Без целевых аннотаций отмечены 246 изображений train и 30 изображений val.

Распределение объектов в валидационной выборке:

| Класс | Количество объектов | Изображения с классом |
|---|---:|---:|
| `helmet` | 201 | 107 |
| `vest` | 171 | 109 |
| **Всего** | **372** | **143 изображения в выборке** |

Одно изображение может содержать оба класса, поэтому количества изображений по классам не суммируются. Количества объектов train и test отдельно ещё не подсчитаны.

## Проверка данных

Выполнена выборочная визуальная проверка обучающего пакета `train_batch0.jpg` и сравнение валидационной разметки `val_batch2_labels.jpg` с предсказаниями `val_batch2_pred.jpg`.

На просмотренных примерах подтверждено соответствие целевых классов каскам и жилетам. Проверены рамки на объектах разных размеров, при различных ракурсах и частичных перекрытиях.

Сравнение разметки и предсказаний позволило выделить удачные обнаружения и примеры для дальнейшего улучшения модели и данных.

## Фоновые примеры и hard negatives

В наборе присутствуют бытовые и офисные сцены, а также люди в обычной одежде. Такие изображения дают модели примеры фона и нецелевых объектов.

При проверке обнаружен полезный **hard negative**: дорожный конус на `image23.jpeg`, для которого модель выдала класс `vest` с confidence около 0,5. Этот пример можно использовать для анализа ложных срабатываний на ярких предметах, похожих на СИЗ.

Для дальнейшего расширения набора целесообразно добавлять проверенные примеры яркой обычной одежды, головных уборов и предметов, сходных с касками и жилетами.

## Ограничения и особенности данных

- Возможны ошибки и пропуски в исходной разметке.
- Мелкие и частично перекрытые объекты могут обнаруживаться хуже.
- Датасет содержит преимущественно строительные сцены, поэтому качество модели на других типах изображений может отличаться.
- Полная проверка дубликатов между выборками не проводилась.

Указанные ограничения необходимо учитывать при оценке результатов модели.

## Результат использования

**Датасет успешно использован для первого дообучения YOLO26n на двух классах СИЗ.** Обучение выполнено в Google Colab в течение 30 эпох; сохранены лучшие веса, параметры эксперимента, графики и примеры предсказаний.

В финальной проверке лучших весов на validation получены:

| Метрика | Значение |
|---|---:|
| Precision | 0,9154 |
| Recall | 0,7582 |
| mAP50 | 0,8588 |
| mAP50–95 | 0,5033 |

Получен рабочий специализированный детектор для дальнейшей интеграции в проект.
