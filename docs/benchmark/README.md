# Этап 9: REST API и benchmark на CPU

## Условия

Измерения выполнены 26.10.2026 на CPU AMD Ryzen 5 5600H.
Python 3.12.3, PyTorch 2.14.1+cpu, Ultralytics 8.4.188,
ONNX Runtime 1.31.0. Использовано видео data/test1.mp4.
GPU/Edge AI-платформа не использовалась; сравнение выполнено
между PyTorch и ONNX Runtime на CPU вместо TensorRT.

Измерения проведены в отдельной копии проекта тем же Python-окружением.
Исходные веса и видео не изменялись. События тестового прогона
сохранялись отдельно от событий основного приложения.

## Проверка REST API

API запущен совместно с настоящими моделями и обработкой видео.
В проверке использован свободный локальный порт; в обычном приложении — 8000.

- GET /health, /status, /cameras: HTTP 200.
- GET /events и /events/{event_id}: чтение сохранённых событий проверено.
- Существование подтверждающего JPG проверено.
- POST /config/thresholds: HTTP 202; значения фактически применились между кадрами.
- POST /config/zones: HTTP 202; полигон фактически изменился между кадрами.
- Некорректные пороги и недостаточное число точек: HTTP 422.
- Неизвестный UUID события: HTTP 404.
- Изменённые настройки восстановлены; YAML не изменялся.

Машиночитаемый результат: api_check.json.

## PyTorch и ONNX

Сравнивалась одна PPE-модель, а не полный конвейер.
Одинаковые первые 205 кадров, 5 кадров прогрева исключены,
200 измерений. Вход: 640, batch=1, rect=False,
confidence=0.40, classes=[0, 1]. Измеряется полный predict();
чтение видео в этот интервал не входит.
Запуски выполнены последовательно в отдельных процессах.
RAM — максимальное наблюдаемое RSS всего процесса, включая библиотеки.
В JSON названия *_mb соответствуют MiB (деление на 1024**2).

| Формат | Размер, MiB | FPS | Среднее, мс | P95, мс | Max, мс | RAM процесса, MiB |
|---|---:|---:|---:|---:|---:|---:|
| PyTorch | 5.18 | 20.99 | 47.64 | 52.32 | 59.58 | 526.69 |
| ONNX Runtime | 9.35 | 10.00 | 99.97 | 124.22 | 168.09 | 585.33 |

ONNX в данном прогоне медленнее PyTorch. Экспорт подготовлен,
но в основном приложении сохранён PyTorch.
Проверка эквивалентности качества двух форматов отдельно не выполнялась.

## Полный конвейер

Работали baseline-детектор, tracking, PPE на crop людей,
smoke/fire, ROI, временные правила, запись JSON/JPG и API.
Все модели — PyTorch. Экспериментальный spill выключен.

Прогон headless: рамки и подписи рисовались, но окно,
imshow и ожидание клавиатуры были отключены.
Поэтому значения характеризуют работу без экранного вывода.
Первые 5 кадров исключены, измерено 200 кадров.

| Компонент | Среднее, мс | P95, мс | Максимум, мс |
|---|---:|---:|---:|
| capture | 2.00 | 3.83 | 6.42 |
| preprocessing | 4.61 | 6.49 | 25.21 |
| inference | 94.09 | 123.54 | 178.18 |
| postprocessing | 1.81 | 2.45 | 3.80 |
| event_processing | 0.94 | 0.91 | 22.80 |
| other | 8.33 | 18.89 | 37.52 |
| total_pipeline | 111.78 | 149.05 | 198.95 |

Средняя производительность: **8.95 FPS**.

Preprocessing, inference и внутренний postprocessing взяты из result.speed
и суммированы по всем вызовам моделей за кадр.
К postprocessing добавлена проверка СИЗ и подготовка полигона.
Event processing включает временные правила и сохранение событий.
Other включает работу вне этих таймеров: дополнительные преобразования,
подготовку crop, tracking вне внутренних таймеров и визуализацию.
Total pipeline измерен независимо от суммы компонентов.

## Воспроизведение

Из корня проекта при остановленном основном приложении:

```bash
python scripts/benchmark_model.py models/best.pt data/test1.mp4
python scripts/benchmark_model.py models/best.onnx data/test1.mp4
python -m scripts.benchmark_pipeline
```

Для последней команды в конфигурации должны быть data/test1.mp4,
CPU, модели .pt и spill.enabled: false.
Новые измерения сохраняются в runs/benchmark.
Изменения входного видео, нагрузки системы и настроек влияют на результат.
