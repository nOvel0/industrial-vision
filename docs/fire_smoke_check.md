# Проверка обнаружения дыма и огня

## Модель и параметры

Использована готовая YOLOv8n, дообученная на D-Fire.
Собственное обучение модели дыма и огня не выполнялось.

Источник:
https://huggingface.co/rabahdev/fire-smoke-yolov8n

Версия репозитория весов: 13017fe.
Файл весов в проекте: models/fire_smoke.pt.

Классы:

- 0 — smoke;
- 1 — fire.

Параметры:

- confidence: 0.40;
- imgsz: 640;
- устройство: CPU;
- подтверждение: 3 из 5 обработанных кадров;
- cooldown: 10 секунд отдельно для дыма и огня.

Порог confidence является начальной настройкой.
Модель анализирует полный кадр.

## Результаты проверки

| Файл | Сценарий | Результат |
|---|---|---|
| smoke_01.mp4 | Дым и пламя | smoke_detected с кадра 42, fire_detected с кадра 54 |
| smoke_02.mp4 | Дым с начала ролика | smoke_detected с кадра 5 |
| fire_01.mp4 | Пламя | fire_detected с кадра 5 |
| negative_smoke.mp4 | Негативный пример: пар или туман | Подтверждённых событий дыма и огня нет |
| negative_smoke_01.mp4 | Негативный пример: пар или туман | Подтверждённых событий дыма и огня нет |
| negative_fire.mp4 | Сварка с небольшим количеством видимого дыма | Событий огня нет; сформированы события дыма |

На положительных примерах подтверждено формирование событий.
На двух проверенных роликах с паром и туманом подтверждённых
ложных событий не зафиксировано.

Сварка рассматривается как негативный пример для огня.
Поскольку в ролике присутствует видимый дым, события
smoke_detected нельзя автоматически считать ложными.
Правильность локализации дыма требует визуальной проверки рамок.

Повторы событий в журнале происходят с интервалом
не менее установленного cooldown.

## Задержка события дыма

Файл: smoke_02.mp4.
Частота исходного видео: 30 FPS.
Дым устойчиво виден с первого кадра.
Первое событие smoke_detected зарегистрировано на кадре 5.

Задержка по времени исходного видео:

(5 - 1) / 30 = 0.133 с.

В данном сценарии задержка меньше ориентира 5 секунд.
Измерение характеризует обнаружение уже присутствующего дыма
при запуске ролика. Появление дыма посреди сцены отдельно
не проверялось.

Это значение не является задержкой реального времени
полного конвейера: файл может обрабатываться медленнее
исходной частоты кадров.
